# Example diagrams

Notes that Archslate opens as diagrams. Copy this folder (or one note) into your vault: each note has the property
`archslate: diagram`, so with the plugin turned on a click opens it as a diagram. Here on GitHub, and in Obsidian
without the plugin, they are notes with a code block. The web app opens them too (**Open…**).

| Note | What it is | What it shows |
| --- | --- | --- |
| [URL shortener](URL%20shortener.md) | the classic interview question | a cache in front of the database, a stacked service (`x3`), id ranges from a coordinator, an async click queue, flows for the read and the create paths, estimates in a table |
| [Chat app](Chat%20app.md) | WhatsApp-style messaging | an open connection (`<->`), `xN` gateways, presence, a sticky note, three flows (one walks the connection back to the phone) |
| [Rate limiter](Rate%20limiter.md) | a token bucket the gateway asks before every request | `direction right`, details on links, a flow that ends at the limit |
| [Orders platform](Orders%20platform.md) | one system in three versions: a monolith, then services, then an outbox | saved versions: open **Changes** to see what changed between them |

The notes are generated by `node scripts/examples-source.mjs` with Archslate's own file format (the same code the
plugin and the agent skill's command-line tool use), so each one is exactly what the plugin writes. An AI agent with
the skill ([skills/system-design-diagram](../skills/system-design-diagram)) makes notes like these from a request.
